## 難易度・サンドボックスモード

| 難易度   | 初期資金  | 維持費倍率 | 災害発生率倍率 |
| -------- | --------- | ---------- | -------------- |
| イージー | 350,000円 | 0.8倍      | 0.5倍          |
| ノーマル | 250,000円 | 1.0倍      | 1.0倍          |
| ハード   | 150,000円 | 1.2倍      | 1.5倍          |

**サンドボックスモード**（資金∞）: すべての建設がコスト0、維持費なし。ただし火災/病気による被害費（-500円/件）は資金から差し引かれる。破産判定の対象外。初期設定画面またはゲーム中の設定メニューでいつでもON/OFF可能。

### 住宅・商業・工業（L1〜L4、自動成長）

建設コストは0円（道路や既存建物に隣接して自動発生、または既存タイルの高層化）。「人口」欄は住宅=居住人口、商業・工業=雇用数として需要モデルに使われる。

| レベル | 住宅 人口 / 税収 | 商業 人口 / 税収 | 工業 人口 / 税収 |
| ------ | ---------------- | ---------------- | ---------------- |
| L1     | 10人 / 30円      | 5人 / 45円       | 15人 / 40円      |
| L2     | 50人 / 90円      | 25人 / 130円     | 60人 / 110円     |
| L3     | 200人 / 220円    | 100人 / 300円    | 220人 / 270円    |
| L4     | 500人 / 450円    | 250人 / 600円    | 550人 / 520円    |

住宅・商業・工業に月額維持費はかからない（維持費が発生するのはインフラ・ランドマークのみ）。

## 成長モデル

毎フレーム、固定タイムステップ（`SIM_TICK_MS = 1000/60`ms 刻み）で `grow()` が呼ばれる。各空きタイル・各ゾーンタイルについて、以下の確率でイベントが発生する。

- **新規建設**（道路に隣接する空きタイル）: `baseRate(0.02) × 都心バイアス × 駅ブースト × ローカルペナルティ × 需要ボーナス`
- **波及建設**（他の建物に隣接する空きタイル、道路隣接は不要）: 上記 × `spilloverFactor(0.2)`
- **高層化**（L1〜L3のゾーンタイル、Lv4未満）: `baseRate(0.02) × upgradeFactor(0.4) × 都心バイアス × 駅ブースト × ローカルペナルティ`（商業のみ、駅+学校+警察の三者シナジー成立時は追加で`×1.2`）

新規/波及建設で配置されるゾーン種別（住宅/商業/工業）は、各需要を重みとした抽選で決まる（住宅は`需要×2`で優遇）。

- **都心バイアス**: マップ中心からの距離に応じて`0.3〜1.0`（中心ほど成長しやすい）
- **駅ブースト**: 駅から±4タイル（チェビシェフ距離）以内は成長速度`×1.5`
- **ローカルペナルティ**: そのタイルが電力圏外なら`×0.6`、給水圏外なら`×0.3`（都市全体の供給率とは別に、タイル単位で判定・乗算される）
- **需要ボーナス**: 該当ゾーンの需要値（0〜100、中立50）を`1 + (demand-50)×0.006`で成長倍率に変換し、`0.7〜1.3`にクランプ

## 需要モデル（雇用バランス）

マップ面積に依存しない「雇用バランスモデル」。住宅人口の一部を働き手、商業+工業人口の合計を求人数とみなし、需給比から3種の需要（0〜100）を算出する（`monthlyUpdate()`内で毎月再計算）。

```
jobs    = 商業人口 + 工業人口
workers = 住宅人口 × 就業率(0.5)

residentialDemand = clamp( 50 × jobs / workers )       # 雇用に対して住宅が足りているか
businessDemand    = clamp( 50 × workers / jobs )       # 住宅に対して商業+工業が足りているか
commercialDemand  = clamp( businessDemand × 2 × (1 - 商業シェア) )
industrialDemand  = clamp( businessDemand × 2 × (1 - 工業シェア) )
```

住宅・雇用が共に0（ゲーム開始直後）の間は、3需要すべてが起点値75になる（何を建ててもよい高需要）。

## 都市パラメータとカバー率モデル

治安度・安全度・教育度・医療度（0〜100）は、**距離ではなく「人口あたりの必要棟数に対する充足率」** で決まる。

```
必要棟数 = max(1, ceil(人口 / populationPerUnit))
```

| 施設   | populationPerUnit |
| ------ | ----------------- |
| 警察署 | 2,500人/棟        |
| 消防署 | 2,500人/棟        |
| 学校   | 3,000人/棟        |
| 病院   | 3,000人/棟        |

充足率 `ratio = 現在棟数 / 必要棟数` から目標値(target)を区分線形で算出し、毎月その25%（`smoothing`）だけ現在値が目標に近づく（急激な変動をせず滑らかに追従する）。

| ratio                | target                       |
| -------------------- | ---------------------------- |
| 0（施設なし）        | 20（baseLevel）              |
| 1（必要数ちょうど）  | 80（fullLevel）              |
| 1.25以上（過剰供給） | 90（overProvisionMax、上限） |

シナジー成立時はさらにボーナスが加算され、最終的な上限は100（シナジーキャップ）。

観光度・国際化度（0〜100）は必要棟数の概念がなく、スタジアム/空港の棟数から直接目標値を算出し同様に平滑追従する（スタジアム1棟＝観光度目標+40、空港1棟＝観光度目標+25・国際化度目標+50、各100でクランプ）。

## 電力・給水

発電所・水処理施設は上記のカバー率モデルとは別に、**円形の供給範囲**を持つ（人口比の必要棟数は使わない）。

| 施設       | 供給半径（円形距離） |
| ---------- | -------------------- |
| 発電所     | 20タイル             |
| 水処理施設 | 15タイル             |

毎月、供給範囲内にあるゾーンタイルの割合が電力供給率・給水率（%）として再計算される。供給圏外の個々のタイルは[成長モデル](#成長モデル)のローカルペナルティ（電力×0.6・給水×0.3）を受け、都市全体の供給率が50%未満だと[インフラ不足ペナルティ](#インフラ不足ペナルティ)も発生する。

## シナジー効果

施設同士が一定距離（マンハッタン距離）以内にあると、対応するレベルの目標値にボーナスが加算される（同種の組が複数あっても加算は重複しない、成立/不成立のブール判定）。

| シナジー                    | 距離条件     | 効果                       |
| --------------------------- | ------------ | -------------------------- |
| 警察署 + 学校               | 15タイル以内 | 治安度目標+5、教育度目標+5 |
| 学校 + 病院                 | 15タイル以内 | 教育度目標+5、医療度目標+5 |
| 駅 + 学校 + 警察署（3施設） | 20タイル以内 | 商業高層化確率 ×1.2        |

## ランドマークの効果

ランドマークによる商業税収ボーナスは2系統ある。

1. **全市的な観光/国際化ボーナス**: `(観光度 + 国際化度) × 0.005` を商業税収全体に加算（最大+100%）。観光度・国際化度自体は上記カバー率モデルと同様、スタジアム/空港の棟数から目標値が決まり平滑追従する。
2. **近接ボーナス（倍率）**: スタジアム/空港の効果範囲（マンハッタン距離）内にある商業タイルの税収を倍率で押し上げる。

| ランドマーク | 効果半径 | 倍率         |
| ------------ | -------- | ------------ |
| スタジアム   | 20タイル | ×1.5         |
| 空港         | 30タイル | ×1.8         |
| 両方の圏内   | —        | ×2.0（上限） |

## 快適度計算

`calculateComfort()` が唯一の算出元（他の箇所で直接快適度を書き換えることはない）。5要素の重み付き平均に、汚染・スラムの乗算ペナルティを掛けて算出する。

| 要素     | 重み | 算出方法                                                                             |
| -------- | ---- | ------------------------------------------------------------------------------------ |
| 緑地     | 25%  | 公園から±10タイル（チェビシェフ距離）以内のゾーンタイルの割合                        |
| 交通     | 20%  | 駅から±8タイル（チェビシェフ距離）以内のゾーンタイルの割合                           |
| 密度     | 20%  | 住宅の平均充足率 u（人口 ÷ (500×住宅タイル数)）が0.6以下なら満点、超過分に応じて減点 |
| 資金     | 10%  | `money / 初期資金 × 50`（0〜100にクランプ）                                          |
| サービス | 25%  | 治安度・安全度・教育度・医療度の平均                                                 |

```
comfort = (緑地×0.25 + 交通×0.20 + 密度×0.20 + 資金×0.10 + サービス×0.25)
          × (1 - 0.3 × 汚染度/100)   # 汚染ペナルティ 最大-30%
          × (1 - 0.4 × スラム化率/100) # スラムペナルティ 最大-40%
```

## インフラ不足ペナルティ

`calculatePenalties()` が毎月、成長速度補正(`growthPenalty`)と税収補正(`revenuePenalty`)を算出する。複数の不足が重なると**乗算**され急速に悪化する（例: 電力・給水とも完全不足なら成長は`0.6×0.3=0.18`倍）。

| 条件             | 成長への影響（最大） | 税収への影響（最大） | その他                                  |
| ---------------- | -------------------- | -------------------- | --------------------------------------- |
| 電力供給率 < 50% | -40%                 | -20%                 | —                                       |
| 給水率 < 50%     | -70%                 | -30%                 | 病気の発生確率 ×3（給水なしタイル個別） |
| 治安度 < 40      | -50%                 | —                    | —                                       |
| 安全度 < 40      | —                    | —                    | 既存火災の勢いを最大2倍に増幅           |
| 教育度 < 40      | -40%                 | -15%                 | —                                       |
| 医療度 < 40      | —                    | —                    | 既存病気の勢いを最大1.5倍に増幅         |
| スラム化率 > 0   | 最大-50%（率に比例） | —                    | —                                       |

教育度が60以上の場合は逆に税収ボーナスが付く（`+15% + (教育度-60)×0.25%`、教育度100で最大+16%、全税収が対象）。

## 災害（火災・病気）

設定で「災害システム」をONにした場合のみ発生する。難易度の災害発生率倍率（イージー0.5倍/ノーマル1.0倍/ハード1.5倍）が掛かる。

### 火災

- 発生確率（サンプリングされたタイルごと、月次）: `0.0002 × 難易度倍率`
- 隣接延焼確率: 1%/月
- 消防署の探索範囲: ±15タイル（チェビシェフ距離）、消火成功率90%（成功で-5、失敗は自然減衰-1）
- 火災レベルが10以上に達した建物は**破壊されて更地になる**（被害費500円が月次収支から差し引かれる）

### 病気

- 発生確率（ゾーンタイルのみ、月次）: `0.002 × (1 + 周辺密度/10) × 難易度倍率`。給水されていないタイルはさらに`×3`
- 周辺（±2タイル、チェビシェフ距離）への伝染確率: 5%/月
- 病院の探索範囲: ±10タイル（チェビシェフ距離）、治癒成功率70%（成功で-3、失敗は自然減衰-1）
- 病気レベルが10に達すると**ゾーンタイルが1段階降格**（L1は更地に）し、病気は0にリセット、被害費500円が発生。旧レベルには戻らない永続的な損失

## 公害・スラム化

設定でそれぞれ個別にON/OFFできる（公害システムは災害システムがONの時のみ有効）。

- **公害**: 工業地タイルのみ、レベルに応じて汚染度を直接設定（L1=20, L2=40, L3=60, L4=80）。非工業タイルは毎月-2で自然減衰。都市全体の汚染度(%) は汚染のあるタイルの割合
- **スラム化**: 住宅タイルの周辺11×11（チェビシェフ距離±5）の平均汚染度・治安度からスラム化確率を算出し、確率的にスラム化レベルが進行。レベルが8を超えると**住宅レベルが1段階降格**（L1は更地に）し、スラムレベルはリセットされる。周辺汚染度が20未満かつ治安度が50以上の月のみスラムレベルが回復（-0.5/月）— 放置した荒廃地区は環境改善なしには回復しない

## ゲームオーバーと破産の猶予

サンドボックスモードでない場合、月次収支適用後に資金がマイナスになると `gameOver=true` + 自動一時停止となり、以下の3択モーダルが表示される（即リセットはしない）。

1. 🎮 サンドボックスで続ける（以降は資金無制限）
2. 📂 セーブをロード
3. 🔄 最初からやり直す

## セーブ/ロード

- localStorage 3スロット + JSON エクスポート/インポート
- 保存データは map・状態グリッド（火災/病気/公害/スラム）をフラット配列化し、全要素0のグリッドは`null`として保存する軽量フォーマット（`SAVE_FORMAT_VERSION = 2`）。`powerGrid`/`waterGrid`/月次収支表示用の`lastReport`は毎月再計算される派生値のため保存しない
- 読込時は型・形状（`gridSize`一致）をバリデーションし、不正・非対応データは読込失敗としてトースト通知。個々のフィールド欠損は新規ゲーム相当のデフォルト値で補完する
